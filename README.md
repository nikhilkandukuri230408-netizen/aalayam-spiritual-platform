# 🕉️ Aalayam - Digital Spiritual Services Platform

> India's #1 AI-powered spiritual ecosystem for temple bookings, pooja services, and astrology consultations.

## ✨ Features

- 🛕 **Temple Bookings** — Browse & book darshan slots at top temples across India
- 🪔 **Pooja & Homam** — Book authentic poojas with experienced pandits (online & offline)
- 🔮 **Astrology Consultations** — Video, voice & chat sessions with verified astrologers
- 🤖 **AI Spiritual Assistant** — Personalized horoscope, festival reminders & guidance
- 📊 **User Dashboard** — Track bookings, favorites, and spiritual insights
- 🛠️ **Admin Panel** — Revenue analytics, provider & booking management

## 🎨 Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom design system with saffron/gold/maroon theme
- **Vanilla JavaScript** — SPA routing, AI chatbot, dynamic rendering
